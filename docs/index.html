agent-repl-security

Harness de agente que responde escrevendo código Python num REPL (Code Mode) isolado, com avaliações medidas por rodadas reais. Projeto de estudo, com dados sintéticos.

Gráficos interativos das avaliações

Dez execuções reais: acerto, iterações, tokens e custo. Passe o mouse sobre um ponto para ver o valor.
