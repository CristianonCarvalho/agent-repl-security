agent-repl-security

Harness de agente que responde escrevendo código Python num REPL (Code Mode) isolado, com avaliações medidas por rodadas reais. Projeto de estudo, com dados sintéticos.

Gráficos interativos das avaliações

Dez execuções reais: acerto, iterações, tokens e custo. Passe o mouse sobre um ponto para ver o valor.

REPL (Code Mode) contra tool calling em JSON

Três variantes nos mesmos 20 casos: acerto, iterações, contexto, observação e custo.

Escala dos dados: o que acontece com 60, 600 e 6.000 linhas

O REPL (Code Mode) fica plano e o tool calling em JSON cresce até falhar.

Cálculos fora do repertório da agregação

Mediana e desvio-padrão em 60, 600 e 6.000 linhas: o REPL segue plano e o JSON degrada.
